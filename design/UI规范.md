# UI 规范

本应用使用原生 View 代码构建界面（无 XML 布局、无 Material 组件库）。所有颜色、圆角和通用控件集中在 `AppUi.kt`，页面代码不得自行写死颜色。新增或修改界面前先读本文。

## 1. 基本原则

1. **照片优先**：界面是照片的容器，装饰要克制，不与照片抢视觉。
2. **深色为主**：目前只有深色主题，背景深、内容层级靠色调区分，不靠阴影堆叠。
3. **一个强调色**：只用一种强调色标识"可操作、已选中、进行中"，其他信息用中性色。
4. **状态可见**：连接、选中、进度、已导入都要有明确的形态变化，不能只靠文字。
5. **大触控区**：可点击元素不小于 44dp，主要按钮 52dp。

## 2. 颜色

所有颜色从 `AppUi` 读取，调用 `AppUi.init(context)` 后随系统更新（在 `TransferApplication.onCreate` 中执行）。

| 令牌 | 用途 | 默认值（Android 11 及以下） | Android 12+ 来源 |
|---|---|---|---|
| `background` | 页面底色 | `#101112` | `system_neutral1_900` |
| `panel` | 卡片、底部栏、弹层 | `#1B1D1F` | `system_neutral1_800` |
| `panelHigh` | 次要按钮底色 | `#26292C` | `system_neutral2_700` |
| `line` | 描边、分隔线、进度条底轨 | `#35383C` | `system_neutral2_700` |
| `muted` | 次要文字 | `#A9ACB2` | `system_neutral2_300` |
| `yellow`（强调色） | 主按钮、选中、进度、可点文字 | `#F2C45B` | `system_accent1_200` |
| `onAccent` | 强调色上的文字和图标 | `#241A00` | `system_accent1_800` |
| `accentContainer` | 选中的标签、进行中的按钮底色 | `#4A3B10` | `system_accent1_700` |
| `onAccentContainer` | 强调容器上的文字 | `#FFE08F` | `system_accent1_100` |
| `danger` | 破坏性操作、错误 | `#FF847B` | 固定 |

规则：
- 文字默认白色，次要文字用 `muted`，不要自己挑灰色。
- 强调色上的文字必须用 `onAccent`，强调容器上的文字必须用 `onAccentContainer`。
- `yellow` 这个名字是历史遗留，实际含义是"强调色"，在动态取色下不一定是黄色。
- 不要在代码里写 `0xff...` 颜色字面量。照片上的半透明角标底色 `0xcc101112` 是唯一例外。
- XML 资源里的颜色（如 `ic_unselected.xml`）可以写死，需要随强调色变化的图标用代码着色，参见 `AppUi.applySelectIcon`。

## 3. 圆角

| 元素 | 圆角 |
|---|---|
| 照片格子 | 10dp |
| 角标、徽标 | 8dp |
| 输入框 | 14dp |
| 提示卡片 | 16dp |
| 相机状态条 | 20dp |
| 按钮（主、次） | 26dp |
| 筛选标签、格式选择 | 18–19dp（胶囊） |
| 底部导入栏 | 32dp |
| 底部弹层顶部 | 28dp |

统一用 `AppUi.shape(context, color, radius, stroke)` 生成，不要手写 `GradientDrawable`（选中描边等特殊绘制除外）。

## 4. 间距与尺寸

- 页面左右内边距 12dp。
- 照片网格 3 列，间距 4dp。`GalleryPhotoCell.cellHeight` 里扣除的宽度（左右 24dp + 间距 8dp = 32dp）必须与此保持一致，改间距要同步改这里。
- 常用纵向间距：4、6、8、10dp。
- 按钮高度：主要按钮 52dp，导入栏按钮宽 150dp，弹层内按钮高 50dp。
- 可点击区域最小 44dp；照片上的选择标记触控区 44dp，圆形本体 22dp。

## 5. 文字

使用系统字体，不引入自定义字体。

| 用途 | 字号 | 字重 |
|---|---|---|
| 品牌名 "Zf 传图" | 24（Zf，衬线斜体）/ 22 | 粗体 |
| 页面区块标题 | 22 | 粗体 |
| 弹层标题 | 21 | 粗体 |
| 空状态标题 | 24 | 常规 |
| 日期分组标题 | 16 | 粗体 |
| 正文、按钮 | 14–15 | 按钮粗体 |
| 提示卡片 | 13 | 常规 |
| 辅助说明、计数 | 11–13 | 常规，`muted` |
| 照片角标 | 10 | 常规 |

文案用简体中文，短句，直接说发生了什么和用户下一步做什么。错误提示说明原因和处理方式，不道歉。

## 6. 组件

统一使用 `AppUi` 和 `GalleryScreen` 中已有的构造方法：

| 组件 | 入口 | 说明 |
|---|---|---|
| 文本 | `AppUi.text` | 自带上下 6dp 内边距 |
| 按钮 | `AppUi.button(primary)` | 主按钮用强调色，次按钮用 `panelHigh`，无描边 |
| 传输按钮 | `ProgressActionButton` | 进度用强调色填充，底色为 `accentContainer` |
| 输入框 | `AppUi.input` | 描边 `line`，圆角 14dp |
| 筛选标签 | `AppUi.chip(active)` | 选中为强调容器，未选中为描边 |
| 底部弹层 | `AppSheet` | `message`、`action`、`row` 三种内容，破坏性行用 `danger` |
| 选择标记 | `AppUi.applySelectIcon` | 选中为强调色圆底加对勾，未选中为空心圆 |
| 提示卡片 | `GalleryScreen.status` | `panel` 底，圆角 16dp |
| 进度条 | `GalleryScreen.progress` | 4dp 高，强调色，`line` 底轨 |

新增通用控件时放进 `AppUi.kt`，不要在页面里重复造。

## 7. 照片格子与角标

- 缩略图居中裁剪，轻微放大 1.15 倍以遮住相机缩略图自带的黑边，不影响保存的原图。
- 右上角：选择标记（仅可导入的格式）。
- 右下角：格式角标。非 JPEG 都显示（RAW、视频、HEIF）。
- 左下角："已导入"。
- 选中：3dp 强调色描边，圆角 10dp。
- 视频和 HEIF 目前只能浏览，没有选择标记。

## 8. 页面结构

首页自上而下：顶栏（品牌、更多）→ 相机连接状态条 → 全部/未导入/已导入标签 → 格式与存储卡筛选 → 标题行（计数、全选）→ 提示卡片和进度条 → 照片网格（按日分组）→ 底部导入栏。

预览页：顶部计数与关闭 → 大图（可缩放）→ 文件名、格式、大小 → 缩略图条 → 加入选择、导入。

- JPEG 预览可"查看原图"；RAW 只显示相机内嵌预览，不提供原图按钮。
- 导入栏只在有选中项时显示。
- 空状态用大标题加一句说明，主操作是"连接相机"。

## 9. 状态

| 状态 | 表现 |
|---|---|
| 已连接 | 相机状态条文字用强调色 |
| 未连接、连接中 | 相机状态条文字用 `muted` |
| 导入中 | 提示卡片显示"正在下载 n/m：文件名 · 百分比"，进度条走动，按钮显示进度 |
| 已导入 | 照片左下角"已导入"，出现在"已导入"筛选里 |
| 不可用 | 控件整体透明度 0.4，并禁用点击 |
| 错误 | 提示卡片文字用强调色，必要时弹出底部弹层 |

## 10. 动效

- 切换标签：当前页向外滑出淡出 110ms，新页滑入淡入 210ms。系统关闭动画时直接切换。
- 不加装饰性动画。

## 11. 无障碍

- 图标按钮、选择标记、可点击的行必须设置 `contentDescription`。
- 文字与背景对比度：正文至少 4.5:1。动态取色时 `onAccent`、`onAccentContainer` 来自同一色板，已满足。
- 不能只靠颜色表达状态，必须同时有文字或形状变化。

## 12. 修改界面时的检查清单

- [ ] 颜色全部来自 `AppUi`，没有新增颜色字面量
- [ ] 圆角、间距落在上面的取值里
- [ ] 改了网格间距或页面内边距，同步改了 `GalleryPhotoCell.cellHeight`
- [ ] 可点击区域不小于 44dp
- [ ] 新增的图标按钮有 `contentDescription`
- [ ] 在 Android 12 以上（动态取色）和 Android 11 及以下（琥珀色）各看了一次
- [ ] 提交时不带截图和实机照片（见仓库协作约定）
