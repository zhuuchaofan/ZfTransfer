# UI 规范

本应用使用原生 View 代码构建界面（无 XML 布局、无 Material 组件库）。所有颜色、圆角和通用控件集中在 `AppUi.kt`，页面代码不得自行写死颜色。新增或修改界面前先读本文。

视觉方向是"胶片机身"：暖黑像机身，米白像相纸，黄铜做强调；硬朗的小圆角，计数像胶卷计数器，日期分组顶上带一条胶片齿孔。和 Nikon Zf 的复古外观呼应。

## 1. 基本原则

1. **照片优先**：界面是照片的容器，装饰要克制，不与照片抢视觉。复古元素只放在少数位置（齿孔、计数、品牌字），不铺满。
2. **深色为主**：只有深色主题，背景深、内容层级靠色调和细线区分，不靠阴影堆叠。
3. **一个强调色**：只用黄铜色标识"可操作、已选中、进行中"，其他信息用中性色。
4. **状态可见**：连接、选中、进度、已导入都要有明确的形态变化，不能只靠文字。
5. **大触控区**：可点击元素不小于 44dp，主要按钮 52dp。

## 2. 颜色

所有颜色是 `AppUi` 里的固定常量，不随系统壁纸变化（复古风靠的就是这组固定色调）。

| 令牌 | 用途 | 值 |
|---|---|---|
| `background` | 页面底色 | `#15120E` |
| `panel` | 卡片、底部栏、弹层 | `#1E1913` |
| `panelHigh` | 次要按钮底色 | `#2A231A` |
| `line` | 描边、分隔线、进度条底轨 | `#4A3F30` |
| `ink` | 正文文字（米白） | `#EDE3CF` |
| `muted` | 次要文字 | `#9A8C72` |
| `yellow`（黄铜强调色） | 主按钮、选中、进度、可点文字、计数 | `#C9A25C` |
| `onAccent` | 强调色上的文字和图标 | `#241A08` |
| `accentContainer` | 选中的筛选、进行中的按钮底色 | `#3A2F1E` |
| `onAccentContainer` | 强调容器上的文字 | `#EAD3A0` |
| `filmBase` | 胶片齿孔所在的黑带 | `#0B0907` |
| `scrim` | 照片上角标的半透明底 | `#CC15120E` |
| `danger` | 破坏性操作、错误 | `#FF847B` |

规则：
- 文字默认用 `ink`，不要用纯白；次要文字用 `muted`，不要自己挑灰色。
- 强调色上的文字必须用 `onAccent`，强调容器上的文字必须用 `onAccentContainer`。
- `yellow` 这个名字是历史遗留，实际含义是"黄铜强调色"。
- 不要在 Kotlin 代码里写 `0xff...` 颜色字面量，需要新颜色先加进 `AppUi`。
- XML 资源里的颜色（图标、`styles.xml` 主题）只能写死，改调色板时要一起改：`ic_back`、`ic_more`、`ic_unselected` 用 `ink`，`ic_chevron_right` 用 `muted`，主题的 `colorAccent` 和 `windowBackground` 分别对应 `yellow` 和 `background`。

## 3. 圆角

统一用 `AppUi.corner`（4dp），硬朗为主。

| 元素 | 圆角 |
|---|---|
| 按钮、输入框、提示卡片、筛选、底部导入栏 | 4dp（`AppUi.corner`） |
| 照片格子、选中描边 | 2dp |
| 照片角标 | 2dp |
| 底部弹层顶部 | 8dp |
| 选择标记 | 圆形 |

统一用 `AppUi.shape(context, color, radius, stroke)` 生成，不要手写 `GradientDrawable`（选中描边等特殊绘制除外）。

## 4. 间距与尺寸

- 页面左右内边距 12dp。
- 照片网格 3 列，间距 4dp。`GalleryPhotoCell.cellHeight` 里扣除的宽度（左右 24dp + 间距 8dp = 32dp）必须与此保持一致，改间距要同步改这里；同样依赖这两个数的还有 `LocalImportGallery` 的格子高度（扣除 32dp）和 `MainActivity` 日期标题行的兜底宽度（扣除左右 24dp）。
- 日期标题行高 56dp，顶部 9dp 是齿孔带。
- 常用纵向间距：4、6、8、10dp。
- 按钮高度：主要按钮 52dp，导入栏按钮宽 150dp，弹层内按钮高 50dp。
- 可点击区域最小 44dp；照片上的选择标记触控区 44dp，圆形本体 22dp。

## 5. 文字

使用系统字体，不打包字体文件（中文衬线字体太大，也不是每台手机都有）。

- `AppUi.serif`（衬线斜体）只用于拉丁字母的品牌字 "Zf"，中文一律无衬线。
- `AppUi.mono`（等宽）用于数字类信息：照片计数、日期分组张数、相机状态、已选数量、预览页计数和文件大小、格式角标。

| 用途 | 字号 | 字重 / 字体 |
|---|---|---|
| 品牌名 "Zf 传图" | 24（Zf，衬线斜体，黄铜）/ 22 | 粗体 |
| 页面区块标题 | 22 | 粗体 |
| 照片计数（标题旁） | 13 | 等宽，黄铜，两位数补零 |
| 弹层标题 | 21 | 粗体 |
| 空状态标题 | 24 | 常规 |
| 日期分组标题 | 16 | 粗体；张数 12 等宽黄铜，"06 张" |
| 正文、按钮 | 14–15 | 按钮粗体 |
| 提示卡片 | 13 | 常规 |
| 辅助说明 | 11–13 | 常规，`muted` |
| 照片角标 | 10 | 格式角标等宽 |

文案用简体中文，短句，直接说发生了什么和用户下一步做什么。错误提示说明原因和处理方式，不道歉。

## 6. 组件

统一使用 `AppUi` 和 `GalleryScreen` 中已有的构造方法：

| 组件 | 入口 | 说明 |
|---|---|---|
| 文本 | `AppUi.text` | 默认 `ink`，自带上下 6dp 内边距 |
| 按钮 | `AppUi.button(primary)` | 主按钮黄铜实底；次按钮 `panelHigh` 底加 `line` 描边 |
| 传输按钮 | `ProgressActionButton` | 进度用黄铜填充，底色为 `accentContainer` |
| 输入框 | `AppUi.input` | 描边 `line` |
| 格式、存储卡筛选 | `AppUi.chip(active)` | 方角描边；选中时黄铜描边加强调容器底 |
| 全部/未导入/已导入 | `GalleryScreen` 标签 | 文字加 2dp 黄铜下划线，下方一条通栏细线 |
| 相机状态条 | `AppUi.rules` | 无底色，上下各一条细线，文字等宽 |
| 底部弹层 | `AppSheet` | `message`、`action`、`row` 三种内容，破坏性行用 `danger` |
| 选择标记 | `AppUi.applySelectIcon` | 选中为黄铜圆底加对勾，未选中为空心圆 |
| 提示卡片 | `GalleryScreen.status` | `panel` 底加 `line` 描边 |
| 底部导入栏 | `GalleryScreen.footer` | `panel` 底加 `line` 描边，已选数量等宽 |
| 进度条 | `GalleryScreen.progress` | 4dp 高，黄铜，`line` 底轨 |
| 胶片齿孔 | `FilmEdgeDrawable` | 只用在日期分组标题顶部 |

新增通用控件时放进 `AppUi.kt`，不要在页面里重复造。

## 7. 照片格子与角标

- 缩略图居中裁剪，轻微放大 1.15 倍以遮住相机缩略图自带的黑边，不影响保存的原图。
- 右上角：选择标记（仅可导入的格式）。
- 右下角：格式角标。非 JPEG 都显示（RAW、视频、HEIF）。
- 左下角："已导入"。
- 选中：3dp 黄铜描边，圆角 2dp。
- 视频和 HEIF 目前只能浏览，没有选择标记。
- 每天一组，组标题顶上一条齿孔带，像一卷胶片的边。

## 8. 页面结构

首页自上而下：顶栏（品牌、更多）→ 相机连接状态条 → 全部/未导入/已导入标签 → 格式与存储卡筛选 → 标题行（计数、全选）→ 提示卡片和进度条 → 照片网格（按日分组）→ 底部导入栏。

预览页：顶部计数与关闭 → 大图（可缩放）→ 文件名、格式、大小 → 缩略图条 → 加入选择、导入。

- JPEG 预览可"查看原图"；RAW 只显示相机内嵌预览，不提供原图按钮。
- 导入栏只在有选中项时显示。
- 空状态用大标题加一句说明，主操作是"连接相机"。

## 9. 状态

| 状态 | 表现 |
|---|---|
| 已连接 | 相机状态条文字用黄铜 |
| 未连接、连接中 | 相机状态条文字用 `muted` |
| 导入中 | 提示卡片显示"正在下载 n/m：文件名 · 百分比"，进度条走动，按钮显示进度 |
| 已导入 | 照片左下角"已导入"，出现在"已导入"筛选里 |
| 不可用 | 控件整体透明度 0.4，并禁用点击 |
| 错误 | 提示卡片显示原因，必要时弹出底部弹层 |

## 10. 动效

- 切换标签：当前页向外滑出淡出 110ms，新页滑入淡入 210ms。系统关闭动画时直接切换。
- 不加装饰性动画。

## 11. 无障碍

- 图标按钮、选择标记、可点击的行必须设置 `contentDescription`。
- 文字与背景对比度：正文至少 4.5:1。当前调色板在 `background` 上：`ink` 约 15:1，`yellow` 约 7.8:1，`muted` 约 5.6:1；黄铜上的 `onAccent` 约 7:1。改颜色后要重新核对。
- 不能只靠颜色表达状态，必须同时有文字或形状变化（标签用下划线加粗体，不只变色）。

## 12. 修改界面时的检查清单

- [ ] 颜色全部来自 `AppUi`，没有新增颜色字面量；改了调色板，同步改了图标 XML 和 `styles.xml`
- [ ] 圆角、间距落在上面的取值里
- [ ] 改了网格间距或页面内边距，同步改了 `GalleryPhotoCell.cellHeight` 等三处
- [ ] 可点击区域不小于 44dp
- [ ] 新增的图标按钮有 `contentDescription`
- [ ] 在手机上看过首页、已导入页、预览页和一个弹层，并试过大字体
- [ ] 提交时不带截图和实机照片（见仓库协作约定）
