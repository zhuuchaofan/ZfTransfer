# 取片

> 原名“Zf 传图”。

把尼康 Zf 中的 JPEG 和 RAW 原图，通过相机 Wi-Fi 保存到 Android 手机相册。其他尼康机型会尝试连接，但未经验证；非尼康相机会被拒绝。

这个项目来自一个很具体的需求：拍完照片后，在手机上清楚地选片、预览，再把需要的原图导入相册，作为 SnapBridge 之外的一个选择。

**[下载 Android 安装包（0.7.0）](https://github.com/zhuuchaofan/ZfTransfer/releases/download/v0.7.0/ZfTransfer-0.7.0.apk)** · [版本说明与校验文件](https://github.com/zhuuchaofan/ZfTransfer/releases/tag/v0.7.0)

## 可以做什么

- **取片台**：打开就能看到相机是否连上、有几张新照片，一键“取回这 N 张”。没连相机时显示手机上最近取回的照片。
- **蓝牙唤醒**：配对一次后，相机开机即可在手机上点“连接相机”，应用通过蓝牙打开相机 Wi-Fi 并自动连接，不用每次进相机菜单。
- **印样**：按天分组浏览相机里的全部照片，导入状态、格式、存储卡合并为一个筛选；长按滑动多选，点日期标题选中一整天。
- **预览**：默认清晰预览，双击、双指缩放，JPEG 可按需查看原图；RAW 显示相机内嵌预览。
- **取回**：单张或批量把 JPEG 和 RAW（NEF/NRW/DNG）原图保存到手机相册，进度常驻底部，取回时可以继续浏览；重复取回可跳过。
- **已冲印**：手机上已取回的照片单独成页。
- **新照片自动取回**（默认关闭）：连接后新拍的 JPEG 自动保存，断线期间拍的重连后补下（一次最多 100 张）。

## 适用范围

- Android 10 及以上。
- 当前实测组合：**小米 14 + Nikon Zf**（含蓝牙唤醒）。其他手机、其他尼康机型及固件组合尚未验证；非尼康相机会被拒绝。
- 视频和 HIF 只能浏览，不支持预览和取回；自动取回只处理 JPEG；不支持相机远程拍摄。
- 锁屏时要保持连接，需把应用的省电策略设为“无限制”（小米：设置 → 应用设置 → 应用管理 → 取片 → 省电策略）。
- 大批量长时间传输、故障恢复仍需继续验证。后续计划见 [后续开发计划](docs/后续开发计划.md)。

## 安装和连接

1. 下载上方 `.apk` 文件，在 Android 手机上打开并按系统提示允许安装。已安装 0.5.7 及之后发布版的手机可直接覆盖升级，记录保留。
2. 选一种方式连接相机：
   - **蓝牙唤醒（推荐）**：在应用右上角“更多 → 蓝牙唤醒相机”里配对一次。若手机用 SnapBridge 配对过这台相机，先在手机蓝牙设置里忽略它并强行停止 SnapBridge；在相机上进入“网络 → 连接至智能设备 → 配对（Bluetooth）”，再在应用里点“开始配对”，按提示在手机和相机上确认。之后相机开机，点“连接相机”即可。第一次连接时需输入一次相机 Wi-Fi 密码（与在相机上手动开启 Wi-Fi 时显示的相同），之后加密保存。
   - **手动开 Wi-Fi**：在相机上开启“连接至智能设备 → Wi-Fi 连接”，手机加入相机热点后打开应用，会自动识别；也可以在应用里填写热点名称和密码，确认系统连接请求。
3. 连上后在取片台一键取回新照片，或点“挑着取”进入印样选片。照片保存在手机相册的 `Pictures/ZfTransfer`。

注意：相机同一时间只记住一个蓝牙配对。在本应用配对后，SnapBridge 需要重新配对才能用；反过来也一样。相机在应用断开后会自动关闭 Wi-Fi，下次用蓝牙唤醒或在相机上重新开启即可。

此前安装了开发测试签名包（文件名带 `-debug`）的手机，无法直接覆盖安装发布版；请先确认不需要应用内记录再处理，不要仅为尝试升级就卸载或清除数据。

## 每次提交的自动编译

推送提交后，[GitHub Actions](https://github.com/zhuuchaofan/ZfTransfer/actions/workflows/android-apk.yml) 自动运行单元测试并生成 APK，PR 和手动运行也支持。同一分支连续推送时，优先完成最新一次。

打开对应成功运行，在 **Artifacts** 下载 `ZfTransfer-APK-…`，解压后得到 APK、SHA256 校验和与构建信息。安装包保留30天，测试报告保留14天；下载需要登录 GitHub。

这些是公开测试签名包，不能覆盖使用专用发布签名的 Releases 安装。普通试用请优先下载页首的 Releases 版本；自动编译不会自行发布或替换该版本，也不使用发布私钥。自动测试不能替代手机与相机实测。
