# Zf 传图 · 0.5.6 测试版

面向小米 14 与 Nikon Zf，通过相机 Wi-Fi 浏览照片，并把 JPEG 原图保存到系统相册 `Pictures/ZfTransfer`。

当前功能、已有实机证据及尚未验证的部分见 [开发记录](../开发记录.md)。不能仅凭相机 Wi-Fi 已连接，认定原图下载或全部批量场景已通过测试。

## 使用

1. 在相机「连接至智能设备」中建立 Wi-Fi 热点。
2. 手机手动连接相机热点，保留无互联网连接；返回应用后自动识别。也可在应用菜单「相机 Wi-Fi 配置」中填写名称和密码，由安卓系统请求连接并确认。
3. 点击照片进入缩略预览；点击圆圈选择，或长按后滑动连续选择。预览切换不重新打开窗口。
4. 点「导入原图」。重复项提供取消、跳过已导入和再次导入；原图不重新压缩，不改动相机文件。
5. 在手机相册检查文件。首次连接在前台完成；建立连接后服务可在切后台或熄屏时继续运行。未完成文件不会作为成功导入项保留。

相机 Wi-Fi 必须先开启。系统可能要求权限或连接确认；保存配置后的无人值守重连尚未稳定通过实测。密码仅在手机端填写并加密保存，不发送到聊天，也不写入应用日志。

## 安装

本地当前安装包位于工程上层 `ZfTransfer-0.5.6-debug.apk`，APK 不纳入 Git。此前已在小米 14 覆盖安装并启动过本项目测试包；最后一轮修复仍需完整回归。

```powershell
& 'D:\Android\SDK\platform-tools\adb.exe' install -r 'D:\Projects\ZfTransfer-test\ZfTransfer-0.5.6-debug.apk'
```

沿用公开测试签名，覆盖安装保留下载记录。不要为了更新先卸载应用；卸载或清除数据会丢失历史记录。

Android Studio 打开本目录，使用 Java 17 或以上、Android SDK 36、Build Tools 36.0.0。SDK 位置：`D:\Android\SDK`。Gradle 工程配置为编译平台 36、目标平台 36、最低平台 29。

```powershell
powershell -ExecutionPolicy Bypass -File ..\build-local.ps1
```

## 历史记录与边界

沿用已有下载记录。只有稳定相机标识、照片元数据和手机上可查询、可读取、已发布且大小匹配的 JPEG 文件都能确认时，才显示「已导入」。相机标识缺失、文件被删除或状态不确定时，不误标或自动跳过。再次导入新增副本，不覆盖手机已有照片。

照片先显示快速缩略图。已导入照片自动从已核验的本地原图读取高清预览；未导入照片可点「加载高清预览」，按需把 JPEG 原图读取到应用私有临时缓存，再按屏幕尺寸解码。高清临时缓存不写入相册，也不作为「已导入」证据。大图解码最长边限制为 2560 像素，避免一次解码整张原图占用过多内存；列表的已导入缩略图最长边为 512 像素。读取相机原始缩略图不再统一降到 240 像素，原始缩略图本身较小时仍需原图数据才能变清楚。暂不支持 RAW、后台传输、断点续传、照片编辑和自动开启相机热点。

遵循 GPL-3.0。第三方归属见 [第三方说明](THIRD_PARTY.md) 与应用内关于页面。`test-keystore.jks` 是公开测试密钥，口令为 `android`，仅用于测试覆盖安装，不用于正式发布。

## 异常提示

常见连接、读取、导入和高清预览异常映射为中文说明与处理建议，不直接显示底层英文异常、路径和堆栈。手动操作失败使用深色、暖黄色的自定义底部面板；自动连接失败仅更新页面提示，避免重试期间反复弹窗。面板可打开相关系统设置或分享诊断日志，分享仍由用户选择，不自动发送。停止操作作为正常取消处理，失败不会自动重新批量导入。

系统 Wi-Fi 确认和权限授权弹窗由 Android 显示；设置输入表单和关于页面仍使用原生 Android 控件。四十项测试包括包装网络异常、空间不足、权限、不完整传输及未知错误的信息隔离。实机断网、存储不足、权限拒绝等具体异常场景尚需逐项验收。

## 高清预览缩放

已加载本地原图或高清临时预览后，双击照片在适屏与两倍放大之间切换；双指捏合或张开在一至五倍之间缩放，放大后可以单指拖动。双指缩放以手指中心为基准，并支持中心位置移动。拖动限制在照片边界内；当某一方向的照片仍小于视口，该方向居中。切换照片、替换快速缩略图或改变视口尺寸时重置为适屏状态，避免将上一张的缩放位置套用到下一张。

快速缩略图不启用放大，需等待高清加载完成。缩放仅改变显示矩阵，不重新下载或改动相册原图；当前高清解码最长边仍为 2560 像素，大倍率放大不会增加原图之外的细节。新增七项缩放几何回归测试，总计四十项自动化测试通过。双指触摸手感仍需真实手机操作确认。


## 分层与批量恢复（0.4.0）

图库构建、单元格、预览窗口分别由 GalleryScreen、GalleryPhotoCell、PhotoPreviewDialog 管理。CameraSession 持有相机连接、网络与串行执行器；ImportRepository 管理原有 saved_ 记录、文件验证与 MediaStore 发布；TransferCoordinator/TransferRunner 管理批量任务，TransferQueueStore/TransferQueueCodec 保存剩余项。Activity 仍负责屏幕状态、自动连接策略与图片加载，后续可以继续渐进拆分。

失败或停止后，页面会出现“重试未完成”。重连同一台相机后点击；每项核对完整元数据，再跳过已确认存在的文件，重新下载未完成的整张照片。剩余任务记录可跨应用重启保留。没有可靠相机身份时不支持安全重试；照片元数据或句柄变化时拒绝自动恢复，需要重新浏览选择。新任务替换旧任务前会确认。

这是前台批量恢复，不支持后台服务、熄屏持续传输或字节级断点续传。进程被强制杀死时，尚未发布的 MediaStore 文件可能仍处于待处理状态；本版没有新增启动清理机制。极端情况下，照片发布成功但历史记录落盘失败，无法可靠确认该照片，重试可能产生副本。

验收：47 项本地自动化测试涵盖原协议、选择、缓存、缩放、队列失败/取消/重试、相机身份和任务序列化。真实相机的断网恢复、强制退出后恢复、相册保存与缩放回归需要重新实测，旧版传输证据不能代替本版验收。


## 预览缩略图栏修复（0.4.1）

底部缩略图栏改为可连续滑动浏览全部已读取照片，点击切换时保留滚动位置；上一张/下一张切换到屏幕外的项目时自动使其可见。只创建可视区域附近的缩略图控件，列表长度不再限制为当前照片前后各三张。尚未读取的相机照片仍需在图库点击“继续读取照片”。

本次验证：50 项单元测试通过；小米 14 固定40项列表的实机控件测试通过首次显示、首尾可达、点击与滚动位置保持。该测试不证明相机原图传输通过。


## 持续连接服务（0.5.0）

连接相机时启动 connectedDevice 前台服务，显示连接通知并提供“断开”。请允许应用通知；拒绝通知不会阻止服务启动，但通知栏可能不显示连接入口，可用应用菜单“停止 / 断开”。返回、切换应用、熄屏和页面重建不再主动释放 Wi-Fi 请求或相机会话。图库状态与批量任务由应用级 ConnectionRuntime 持有，页面只订阅显示状态，恢复页面时复用现有列表和连接。

服务串行执行相机操作与约十五秒一次的空闲心跳；意外掉线后以五秒起、上限一分钟的退避间隔重试，实际受十五秒调度粒度影响。仅对已成功连接过的 Wi-Fi 请求尝试恢复，不反复弹出首次授权。手动断开后停止服务、释放网络请求和锁，并抑制重连；也可在 Android 系统中停止服务。进程被强制停止、系统杀死或应用更新时不能保证连接继续，本版不自动复活被停止的服务。

有连接或任务时持有 CPU/Wi-Fi 锁，熄屏后仍可通信，会增加手机和相机耗电。CPU 锁使用有超时的租约并由服务更新，断开、失联和服务销毁时释放。相机热点是否保持由固件和“照相机关闭时上传”共同决定；本应用不能在热点消失后仅靠 Wi-Fi 唤醒相机。

此前 0.4.x 的“仅前台传输”限制已由本节替代；旧版传输证据仍不等于本版后台原图下载验收。字节级断点续传仍未实现。


### 小米 14 的实测设置

菜单“后台连接设置”可打开应用信息。小米系统中需将本应用的“省电策略”改为“无限制”，并允许通知。此次实测在默认“智能限制后台运行”下，前台服务仍存在，但熄屏后 CPU 锁被系统禁用、心跳停止且手机随后换网；改为“无限制”后，熄屏近两分钟仍连续收到约十五秒一次的相机响应。这个短时结果不等于长时间待机和后台批量传输全部通过。


0.5.0 实测补充：开启相机关机上传、手机省电无限制后，用户将相机电源拨到OFF，手机持续熄屏约一分半，七次连续设备信息心跳成功。此结果只证明短时会话保持，不证明长时间连接、关机原图下载或系统杀进程后自动恢复。最终包手动断开会移除服务与CPU锁，已验证。


## 自动识别与预览接口测试（0.5.1）

手机在系统 Wi-Fi 中连接相机热点后返回应用，可自动读取相机型号、身份和照片，并记住验证成功的地址及可获得的热点名称。手动连接时无需填写应用内 IP。应用内 Wi-Fi 名称和密码用于应用主动请求热点连接，属于可选配置；Android 系统保存的热点密码不能由本应用直接读取或复制。

修复手动“连接相机”直接选择第一个 Wi-Fi 网关的问题。手动与自动流程共用相机网络选择：优先应用请求的网络、已知相机热点名称、NIKON 热点，再使用无互联网且匹配已验证地址的回退；只有用户明确设置高级 IP 时允许自定义地址。普通家用网络不再被直接当作相机。端口拒绝提示改为“未找到相机服务”，不再直接断言相机尚未准备好。

预览速度测试：连接并读取照片，打开希望测试的照片后返回图库，在菜单选择“预览速度测试”。对同一照片依次请求普通缩略图、尼康大缩略图（0x90C4）与全高清候选（0x920F），记录实际宽高、字节数和耗时。原图只显示文件大小，不下载。返回数据只在内存中检查尺寸，不写入相册、缓存或导入记录。相机拒绝某个读取时记录拒绝并继续；网络或不完整传输则中止测试并恢复连接。此入口是诊断测试，尚未将默认预览替换为中等尺寸。

协议候选依据 libgphoto2 的 Nikon 定义，不保证每台相机或每种 Wi-Fi 模式支持：
- https://github.com/gphoto/libgphoto2/blob/v2.5.31/camlibs/ptp2/ptp.h
- https://github.com/gphoto/libgphoto2/blob/master/camlibs/ptp2/cameras/nikon-zf.txt


实测：同一张约10.51MB JPEG，普通预览160×120/10.4KB/29ms，大缩略图640×424/106.4KB/81ms，全高清1620×1080/619.9KB/169ms。单位KB为1024字节，时间仅为本次接口读取，不包含完整显示链路。全高清接口可作为后续中等预览实现的依据；本次尚未切换默认预览策略。


## 默认清晰预览（0.5.2）

打开照片时优先使用已存在的本地原图，否则自动获取尼康全高清预览，失败时尝试大缩略图；不自动下载完整原图。清晰预览独立缓存，预算48MB，只接受合适尺寸的可解码图片，不作为“已导入”证据。仍可点击“查看原图”明确获取完整JPEG临时预览，或“导入这张原图”保存到相册。

实机验证：未导入照片自动取得1620×1080、640196字节预览；重新打开同张照片命中缓存，未新增0x920F请求；未触发原图下载。60项单元测试通过。此前默认原图预览策略已由本节替代。


## 连接就绪处理（0.5.3）

识别新网络后先保留约1.5秒的稳定窗口，重复点击不重新延长同一窗口。普通网络已有明确非相机名称时，即使离线且网关与相机地址相同，也不选为相机。真正读取设备信息后才显示“已连接”。

前两次临时网络连接错误先提示等待并自动重试，持续失败会显示实际问题；相机协议拒绝不被当作网络切换而静默。系统手动连接已验证可用时，取消另一个尚未完成的Wi-Fi请求；旧请求失败不覆盖已确认连接状态。手动停止同时取消待执行的连接尝试。

65项单元测试覆盖等待窗口、重复点击、换网、有限静默重试及非相机网关拒绝。相机热点开启仍需手机真正加入该热点；如果关机后热点已消失，本应用不能仅靠Wi-Fi将其唤醒。


## 预览布局与缩放动效（0.5.4）

“原图”改为照片预览页右上角的轻量文字入口，底部原大按钮移除。点击入口会先显示待加载原图大小，确认后才下载临时原图；取消不发起原图传输。已经在查看本地或临时原图时，入口置灰并标注当前原图状态。

双击使用约280毫秒减速过渡，以双击位置为中心放大至2倍，再双击平滑复原。拖动、双指开始操作、取消触摸、换图、尺寸变化及视图移除时取消旧动画。遵循系统动画关闭设置。67项单元测试通过；独立小米14测试验证了放大与复原的中间帧、终点和换图取消。测试不涉及真实照片传输，独立测试包已卸载。


## 底部自动读取与预览操作（0.5.5）

向后浏览接近列表底部时自动追加读取下一批照片，已有照片与选择保留，也可点继续读取按钮。预览页点击导入或加入／移出选择后停留在当前照片，导入期间禁止重复操作，完成后更新已导入状态并取消对应照片的选择；失败未完成的照片保持选中。导入记录仍需手机文件验证，重复导入仍显示三种选择。

新增自动读取与导入完成后的停留、取消选择行为尚待连接相机实测。


## 预览进度与缩略图栏追加（0.5.6）

预览导入按钮显示下载百分比；滑动底部缩略图栏接近尾部时自动追加读取。传输中隐藏剩余任务入口，任务结束后仍有未完成照片才显示“继续导入未完成的 N 张”。新增行为仍需相机实测。
